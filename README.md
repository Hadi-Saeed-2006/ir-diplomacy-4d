# 🌐 DIPLOMATIQ 4D

## Global Relations & Diplomacy Intelligence Dashboard

**DIPLOMATIQ 4D** is a lightweight, portfolio-grade geopolitical analytics platform that combines interactive geospatial visualization, diplomatic relationship analysis, time-based event exploration, and transparent risk indicators.

> **4D = 3D geographic space + time.**

### 🎯 Project objective

Answer a practical analyst question:

**Where are diplomatic and geopolitical signals concentrating, how are relationships changing over time, and which areas deserve attention?**

### Core modules

- 🌍 **4D Global View** — interactive world map with event severity, impact and time
- 🤝 **Diplomatic Network** — country-to-country interaction graph
- 📊 **Risk & Trends** — event velocity, impact and explainable pressure score
- 🧠 **Analyst Brief** — concise data-driven executive summary

### Technology

`Python` · `Pandas` · `NumPy` · `Plotly` · `Streamlit`

### Design philosophy

This project deliberately prioritizes **reliability, clarity and low operational complexity**. The first release uses a small synthetic dataset so the dashboard runs without API keys or external services. Live data ingestion and NLP are planned only after the core application is stable.

### Data integrity

The initial dataset is synthetic demonstration data. It is **not real intelligence and should not be interpreted as a sovereign risk rating or foreign-policy recommendation**. Future live-data modules will document source, retrieval time, transformations and limitations.
