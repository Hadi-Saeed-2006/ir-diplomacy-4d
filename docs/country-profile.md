# Country Intelligence Profile

The Country Intelligence Profile is the next analytical layer of DIPLOMATIQ 4D.

For a selected country, the dashboard combines:

- event volume and severity
- aggregate impact
- diplomatic counterparties
- relative pressure score
- recent news signals when the optional GDELT layer is enabled

The profile is a **decision-support view**, not an official country-risk rating or intelligence assessment.

## Interpretation

The profile should answer four practical questions:

1. What diplomatic activity is occurring?
2. Which counterparties are most active?
3. Is activity becoming more or less intense over the selected period?
4. What recent media signals may warrant further primary-source validation?

News coverage is treated as a signal about media attention, not proof that an event occurred. GDELT DOC 2.0 provides article-list search and JSON output for this type of coverage analysis.
